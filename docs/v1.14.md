# HAPI fork v1.14

Date: 2026-11-02

## Skill previews

- Fixed skill catalog refresh for directly entered, pasted or restored prefixes
  such as `$pony`, including recovery from a failed initial catalog request.
  Requests share in-flight discovery and are limited while typing; cached
  previews stay visible during refresh.
- The existing picker lists every matching discovered skill with its complete
  reference and description. The selected skill's description now expands in
  full. Selecting a row inserts the canonical reference, including plugin names.
- Added distinct loading, empty-catalog, no-match and failure messages, with
  **Reload skills** for failed or empty discovery. Escape dismisses the picker
  without a delayed catalog response reopening it for the same query.
- Bumped `FORK_VERSION` once from `1.13` to `1.14`, synchronized the README
  footer and updated the command/skill guide.

## Scope and compatibility

Only the web client, shared fork counter and documentation changed. The Hub API,
HAPI Runner, native skill enumeration and skill invocation formats are unchanged.
The web picker uses the session catalog through the existing authenticated API;
it does not read Runner paths from the Hub or introduce a hardcoded plugin list.
Native Codex plugin enumeration still requires the v1.13 Runner integration.
Other agents and slash/file suggestions keep their existing selection behavior.

## Verification

- 69 focused web jsdom tests passed, including recovery after catalog failure,
  all six matching Ponytail skills and descriptions, canonical insertion,
  request coalescing, cached previews, retry, dismissal during discovery,
  status messages and composer/rich-input regressions.
- Web TypeScript check passed. One existing composer test logs that IndexedDB
  is unavailable in jsdom; the test passes and no production data is accessed.
- Production frontend build, version consistency check and 12 version/update
  script tests passed. The mechanical UI detector returned no findings. The
  build retains existing warnings about font URLs, Browserslist data, PWA
  manifest theme color, dependency annotations and large bundles.
- No browser/Playwright tests, production deployment, service restart or push
  were performed. Actual Hub/Runner behavior on Serweusz remains to be checked
  by the user. The reference project was left unchanged.
