# HAPI fork v1.16

Date: 2026-11-07

## Conversation default agents

- Added a persistent default agent profile per conversation, independently of the
  active profile. Setting the default activates it; ordinary selection changes
  only the active profile. Opening a picker or sending a message never resets it.
- Added a right-click menu and accessible star buttons at the right of profile
  rows, a separate active check, explicit restore/remove actions, and an
  unavailable-profile notice. Renamed the profile-clearing option to **No profile**.
- Added a default-agent field to new-conversation creation, scoped to the selected
  machine, CLI and directory. Folder-picker navigation preserves the scoped
  draft. Import/reopen applies the selected default to the existing conversation;
  a save failure is reported without launching a duplicate conversation.
- Extended Hub discovery to use existing machine-scoped Bash RPC before a session
  exists. The existing path check validates the starting directory before the
  bounded profile probe. Authentication and namespace isolation are preserved;
  instructions are excluded from API catalog summaries.
- Validated and saved the chosen instructions before dispatching a fresh session
  launch. A preparation failure prevents dispatch and removes the unlaunched
  session stub. Existing conversations keep their current active profile and
  acquire no default automatically. Resume/reopen carries both snapshots.
- Bumped `FORK_VERSION` once from `1.15` to `1.16`, synchronized the README footer,
  and updated the profile usage guide and existing UI locales.

## Scope and compatibility

Changed the Hub, web/PWA client, shared additive request/state types and
documentation. **HAPI Runner implementation was not modified; no Runner update
is required.** Existing RPC methods and CLI message formats are reused. Upstream
app/package versions remain unchanged and no dependencies were added. Defaults
apply saved instructions through the existing profile delivery path; they do not
change native CLI roles, models, permissions or tools. Native terminal,
Telegram and MCP sends retain their existing behavior.
