project directory also deletes its Hub database, credentials and settings before
replacing them with the source copy. The script does not preserve destination
`data/`, `.env` or destination-only Git state. Git/Docker ignore rules do not
filter its directory deletion or recursive copy. Describing this behavior is not
authorization for the agent to run the script or overwrite production state.
