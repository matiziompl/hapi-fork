# HAPI fork v1.17

Date: 2026-11-08

## Remembered agent when creating conversations

- The new-conversation form starts with the agent profile used for the previous
  successful creation, including an explicit **No profile** selection. The
  preference is stored in the browser separately for each Runner machine and
  CLI, and applies across workspace directories.
- Explicit form and folder-picker draft choices take precedence over the
  remembered profile. Canceling or failing a launch does not replace it.
- Imported/reopened conversations remember the requested choice only after its
  profile update succeeds. An explicitly chosen or remembered **No profile**
  also clears the imported conversation's previous selection;
  failures retain the existing recovery notification without repeating import.
- Unavailable remembered profiles remain visible for explicit replacement, with
  a creation-specific message rather than a claim about saved instructions.
- Bumped `FORK_VERSION` once from `1.16` to `1.17`, synchronized the README footer
  and updated the profile guide and existing UI locales.

## Scope and compatibility

Changed only new-conversation frontend preferences, form integration, the
unavailable-profile message, tests and version/documentation files. No Hub API,
RPC format, dependencies or native CLI behavior changed. **HAPI Runner was not
modified and requires no update.** Existing per-conversation defaults remain
stored in the Hub; changing them inside a conversation does not overwrite the
browser's creation preference. Browser storage is not synchronized across devices.
