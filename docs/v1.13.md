# HAPI fork v1.13

Date: 2026-11-02

## Commands and skills

- Added the documented AGY and Codex slash-command catalogs to web/PWA autocomplete.
  Native CLI screens are marked `CLI`, open the real agent terminal, and retain
  the operator's command for explicit submission after the prompt is ready.
  Existing HAPI commands and custom-command precedence remain available.
- Connected Codex shared-session skill discovery to native `skills/list`.
  `$name` and `$[name]` references, including multiple inline/plugin/dotted names,
  become structured native skill inputs. Disabled/unknown skills and code examples
  remain text. Native skill notifications and working-directory changes invalidate
  the catalog.
- Added AGY native skill enumeration so plugin and discovery-manifest skills appear
  under their real names. Skill slash invocations use existing AGY expansion.
- Added an optional native launch mode to the existing authenticated terminal
  protocol. Native terminals use argv launch, scoped credentials, cancellation
  during preparation, and owned process-tree shutdown. Ordinary shell terminals
  retain their behavior. Older wrappers receive an update/reopen requirement.
- Codex terminals attach to the owned shared app-server thread. `/import` uses a
  separate local settings CLI because Codex disallows it in remote clients.
  Native directory changes rebind the existing file/Git handlers and catalogs.
- AGY native terminals acquire an exclusive conversation writer lease. Active or
  queued work blocks opening; idle headless processes are retired first. New chat
  messages remain queued and cancelable until native process exit and shutdown
  verification. Leaving/disconnecting the native terminal closes its process.
- Bumped `FORK_VERSION` exactly once from `1.12` to `1.13`, synchronized README,
  and documented usage and limitations in `docs/guide/native-cli-commands.md`.

## Runner and compatibility

The Runner/session CLI implementation was modified. A CLI update and reopening the
affected session wrappers are required; a Hub rebuild alone is insufficient.
The local Linux x64 baseline binary is
`.tools/runner-v1.13/bun-linux-x64-baseline/hapi` (ignored build output).
The upstream package/protocol version remains separate from the fork counter.
Existing CLI protocols and file formats were reused; terminal fields are additive.

These are native CLI entry points, not replacement browser settings screens.
Account, installed CLI version, remote-mode, OS and device restrictions still
apply. Native audio/editor/clipboard operations use the Runner host. AGY native
conversation switches and terminal-only turns are not migrated into HAPI chat;
chat delivery returns to the original conversation and its HAPI setting overrides.
The iOS and Android applications were not modified.
