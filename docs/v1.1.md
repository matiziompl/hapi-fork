## Workspace explanation

The reference directory `hapi_original` contains a deployment configuration that
installs the prebuilt `@twsxtd/hapi` npm package. It is not a full upstream source
checkout. The working fork now includes the source repository (3,132 entries in
baseline commit `f8e55fb930cde45dd4ef5cc5dd1fac0a047f38b8`), including web, Hub,
CLI, shared code, native applications, documentation and tests. Local dependency
installation and builds add ignored files on top of that source tree.
