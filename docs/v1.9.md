# HAPI fork v1.9

Date: 2026-11-02

## Documentation and Git workflow

- Updated `AGENTS.md` and README to make GitHub publication optional and
  independent of Hub updates and local commits. The operator chooses when to
  push and can accumulate uncommitted iterations or unpublished local commits.
- Local commit commands must work without a remote, network access, a preceding
  fetch/pull, equality with `origin/main`, a clean index or an already committed
  previous release. Unrelated staged work must be preserved.
- When earlier iterations are uncommitted, handoff commands must explicitly
  cover their combined files. Selective updates retain destination `.git`,
  including local history and remote settings; unpublished commits do not block
  the next iteration. Operations that depend on unpublished changes still
  require checking their actual state.
- Incremented `FORK_VERSION` once from `1.8` to `1.9` and synchronized README.
  Application behavior, Runner implementation and communication protocols are
  unchanged.
