# HAPI fork v1.15

Date: 2026-11-04

## Personas and agent profiles

- Added a Personas button to the existing configurable composer toolbar. It can
  be moved/hidden like Status. Its dropdown selects or disables a persona; the
  bottom-right plus opens a larger creator with name and description fields.
- Persisted personas in the Hub's existing atomic settings store, scoped by
  authenticated namespace. Selections are per session and follow resume/reopen
  without overwriting an explicit choice in the destination session.
- Added a searchable Agent selector at the right end of the prompt toolbar,
  outside its scrolling group. It discovers saved profiles on the session's
  machine using existing authenticated Bash RPC, with loading/error/empty states,
  reload and a default-agent option.
- Added bounded Markdown/YAML and TOML discovery for AGY, Codex, Claude, Gemini,
  Copilot, Cursor, Kimi, OpenCode, Grok and Pi extension profiles. Project
  definitions override user definitions. Codex config-file roles and OpenCode
  JSON/JSONC and file prompt references are included. No dependencies were added.
- The Hub snapshots selected instructions separately from visible user text.
  Existing CLI message delivery prepends the snapshot, including live sends,
  reconnect backfill, retries and scheduled sends. Native queue mirrors retain
  the original visible text. Leading skill references remain first, and native
  slash commands, including plugin names, retain their existing behavior.
- Added Hub-side normalization for Claude transcript echoes and AGY interruption
  recovery. Exact stored snapshots correlate through the message identifier;
  combined restores preserve original text, including bare skills and unusual
  message identifiers. If a canceled/removed source cannot be verified, recovery
  leaves the draft unchanged with an explicit message instead of restoring
  hidden instructions.
- Kept profile popovers and the creator above the expanded composer. Added
  translations for the existing English, Russian and Simplified Chinese locales.
- Bumped `FORK_VERSION` once from `1.14` to `1.15`, synchronized the README footer
  and added [usage and limitations](guide/prompt-profiles.md).

## Scope and compatibility

Changed the Hub, web/PWA client, shared additive helpers/types, and documentation.
**HAPI Runner implementation was not modified; no Runner update is required.**
Existing CLI RPC methods and message formats are reused. Upstream app/package
versions remain unchanged. Agent selection applies saved prompt instructions;
models, tools, permissions, hooks and native subagent spawning continue to follow
the existing CLI/session configuration.

The catalog covers saved user/project definitions and documented configuration
roles. Built-ins, transient roles, plugin-only profiles outside those roots,
custom/managed discovery inventories and DSH's provider-specific compositions are
not enumerated. DSH reports discovery unavailable; Hub personas remain usable.
Native terminals, Telegram and MCP sends do not inherit web-composer selections.
The prefix is stored for replay, so this is a UI behavior, not a secrecy boundary
for raw API/database/export inspection or model-generated quotations.
